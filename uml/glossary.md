# Глоссарий проекта WeatherDesk

Глоссарий определяет термины, используемые в документах проекта: [SRS](srs.md), [SDD](sdd/sdd.md), [ADR](adr/), [модель вариантов использования](uml/use-cases.md) и [дополнительные спецификации](supplementary-spec.md).

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| Город | Населённый пункт, выбранный пользователем: название, регион, страна, координаты и часовой пояс, полученные от сервиса геокодинга | SRS REQ-INT-008, UC-01, UC-02 |
| Город по умолчанию | Город, прогноз которого загружается при первом запуске или при выключенной настройке запоминания; по умолчанию Минск (53.90, 27.57) | REQ-FUNC-003, UC-02 |
| Геокодинг | Преобразование введённого названия города в координаты; выполняется сервисом Open-Meteo Geocoding | REQ-INT-008, UC-01 |
| Подсказка | Вариант города в выпадающем списке под строкой поиска (не более 5 вариантов) | REQ-FUNC-001, UC-01 |
| Задержка ввода (debounce) | Пауза 400 мс после последнего нажатия клавиши, по истечении которой отправляется запрос подсказок | REQ-FUNC-001, UC-01 |
| Прогноз | Совокупность текущей погоды, почасового прогноза на 24 часа и прогноза на 7 дней для выбранного города | SRS, UC-02 |
| Снимок прогноза (`WeatherSnapshot`) | Неизменяемый объект с текущей погодой, часовыми и дневными точками, сведениями об источниках и временем получения | SDD 003, SDD 011 |
| Текущая погода | Температура, влажность, давление, ветер, описание и иконка на данный момент, а также минимум и максимум за сегодня | REQ-FUNC-006, UC-06 |
| Почасовой прогноз | Блок из 24 карточек, начиная с текущего часа (или с 00:00 выбранного дня) | REQ-FUNC-008, UC-07 |
| Детали часа | Влажность, давление и ветер для выбранной карточки часа | REQ-FUNC-009, UC-07 |
| Прогноз на неделю | Блок из 7 строк (дней) с иконкой, минимальной и максимальной температурой | REQ-FUNC-010, UC-08 |
| Источник | Один внешний погодный сервис, подключённый через реализацию `IWeatherProvider`: Open-Meteo, Open-Meteo с моделью ECMWF или Met Norway | SDD 002, ADR-0002 |
| Open-Meteo | Бесплатный сервис прогноза погоды и геокодинга; ключ API не требуется | REQ-INT-007, REQ-INT-008 |
| ECMWF | Европейский центр среднесрочных прогнозов погоды; его модель запрашивается через Open-Meteo параметром `models` | ADR-0002 |
| Met Norway | Метеорологический институт Норвегии, сервис Locationforecast; требует заголовок `User-Agent` | ADR-0002, CON-8 |
| Агрегатор (`AggregatingWeatherProvider`) | Компонент, который опрашивает источники параллельно и объединяет ответы; сам реализует `IWeatherProvider` (паттерн Composite) | SDD 005, ADR-0002 |
| Усреднение | Вычисление среднего арифметического числовых значений по тем источникам, которые ответили | SDD 011, UC-03 |
| Основной источник | Источник, чей код погоды и иконка используются в первую очередь (порядок: Open-Meteo, ECMWF, Met Norway) | ADR-0005 |
| Разброс | Разность максимальной и минимальной текущей температуры среди ответивших источников | SYS-FUNC-006, UC-03 |
| «Ответило N из 3» | Подпись о числе источников, давших ответ в последней загрузке | REQ-INT-010, UC-03, UC-12 |
| Тайм-аут | Предельное время ожидания ответа одного источника: 10 секунд | REQ-PERF-002, UC-03 |
| Код погоды (WMO-код) | Числовой код погодных условий по стандарту ВМО; приложение поддерживает 28 кодов | REQ-FUNC-013, приложение C SRS |
| Иконка погоды | Одно из 10 встроенных изображений, выбираемое по коду погоды и признаку «день или ночь» | REQ-INT-004, UC-06 |
| `symbol_code` | Текстовое обозначение погоды Met Norway; переводится в ближайший WMO-код, если другого источника нет | SDD 012 |
| Давление на уровне моря (MSL) | Атмосферное давление, приведённое к уровню моря (`pressure_msl`); используется у всех источников | ADR-0003 |
| Единица давления | мм рт. ст. (по умолчанию) или гПа; переключается пользователем и запоминается | REQ-FUNC-012, UC-10 |
| Местное время | Время в часовом поясе выбранного города, а не компьютера | REQ-FUNC-018 |
| Часовой пояс IANA | Идентификатор вида `Europe/Minsk` из ответа геокодинга | SDD 011 |
| Ручное обновление | Повторный запрос данных кнопкой «Обновить» или клавишей F5; не чаще одного раза в 10 секунд | REQ-FUNC-014, UC-04 |
| Автообновление | Повторный запрос данных каждые 30 минут по таймеру без действий пользователя | REQ-FUNC-015, UC-05 |
| Запрос-дубликат / устаревший ответ | Ответ на запрос для города, который пользователь уже сменил; отбрасывается | REQ-REL-004, UC-02 |
| Состояние экрана | Одно из состояний: загрузка, данные, частичные данные, кэш, нет сети, ошибка сервиса, город не найден | REQ-INT-005, SDD 013 |
| Кэш | Файл `cache.json` с прогнозами 10 последних городов; срок хранения 24 часа (версия 1.1) | REQ-INT-009, UC-12 |
| Настройки (`settings.json`) | Файл с последним городом, единицей давления, темой и избранным | REQ-INT-009, UC-02, UC-10, UC-11 |
| Избранный город | Город, добавленный в список избранного (не более 10, версия 1.1) | REQ-FUNC-005, UC-13 |
| Тема оформления | Светлая или тёмная палитра цветов окна | SYS-FUNC-018, UC-11 |
| Режим раскладки | Wide (от 900 px), Medium (600–899 px) или Compact (менее 600 px) | REQ-INT-002, SDD 018 |
| Журнал ошибок | Файл `%AppData%/WeatherDesk/logs/app.log`, до 3 файлов по 1 МБ | REQ-OBS-001 |
| Слои приложения | Presentation (WPF, MVVM), Application (логика и интерфейсы), Infrastructure (клиенты, файлы) | REQ-MAINT-001, SDD 002 |
| ViewModel | Класс слоя Presentation, хранящий состояние экрана и команды; не знает об Infrastructure | SDD 002 |
| WPF | Windows Presentation Foundation — библиотека интерфейса для Windows | ADR-0001 |
| Актёр (Actor) | Роль, которую внешнее лицо или система играет по отношению к системе (пользователь, другая система, время) | UML, uml/use-cases.md |
| Прецедент (Use Case) | Последовательность действий системы, дающая актёру наблюдаемый результат | UML, uml/use-cases.md |
| Поток событий | Описание хода прецедента: основной, альтернативные потоки и потоки ошибок | UML, uml/use-cases.md |
| Include / extend | Связи между прецедентами: обязательное включение общего поведения и необязательное расширение при условии | UML, uml/use-cases.md |
| Диаграмма активности | UML-диаграмма алгоритма или потока работ | SDD 020 |
| Диаграмма состояний | UML-диаграмма жизненного цикла объекта или экрана | SDD 013 |
| Диаграмма последовательности | UML-диаграмма обмена сообщениями между участниками во времени | SDD 009 |
| draw.io | Бесплатный редактор диаграмм; файлы `.drawio` хранятся в репозитории как XML | ADR-0006 |
