## Информация о проекте:

- Группа: 450501

- Дисциплина: Жизненный цикл разработки программного обеспечения

- Тема: Высота и длина

Проект представляет собой нативное Windows Forms приложение для конвертации величин. Реализована возможность выбирать величины из которой и в которую происходит конвертация. Поддерживаемые величины: дюйм, ярд, сантиметр, метр, американский таракан, шея жирафа, самая
длинная змея, человеческий язык, футбольное поле
